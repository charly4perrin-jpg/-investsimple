📈 Analyse

Derivees, integrales, limites, logarithme, exponentielle, equations differentielles

∂
Derivation
Formules, regles, applications
▼

Formules de base

Fonctions usuelles
(x^n)' = n·x^(n-1)
(sqrt(x))' = 1/(2sqrt(x))
(e^x)' = e^x
(ln x)' = 1/x
(sin x)' = cos x
(cos x)' = -sin x
Regles de calcul
(u+v)' = u' + v'
(ku)' = k·u'
(uv)' = u'v + uv'
(u/v)' = (u'v - uv')/v²
(u∘v)' = v'·u'(v)
Derivees composees
(e^u)' = u'·e^u
(ln u)' = u'/u
(u^n)' = n·u'·u^(n-1)
(sqrt(u))' = u'/(2sqrt(u))

Theoremes fondamentaux

TVI — Theoreme des valeurs intermediaires
Si f est continue sur [a,b] et k est compris entre f(a) et f(b), alors il existe c dans [a,b] tel que f(c) = k. Utile pour montrer qu'une equation a une solution.
Sens de variation
f'(x) > 0 sur I → f croissante · f'(x) < 0 → f decroissante · f'(a) = 0 avec changement de signe → extremum en a
• Ne pas confondre (uv)' = u'v+uv' et (u∘v)' = v'×u'(v(x))
• (ln u)' = u'/u et NON 1/u si u != x
• (e^(2x))' = 2e^(2x), pas e^(2x)
∫
Integration
Primitives, calcul d'aires, proprietes
▼

Primitives usuelles

Fonctions de base
∫x^n dx = x^(n+1)/(n+1) (n≠-1)
∫(1/x) dx = ln|x|
∫e^x dx = e^x
∫cos x dx = sin x
∫sin x dx = -cos x
∫(1/sqrt(x)) dx = 2sqrt(x)
Formes composees
∫u'e^u dx = e^u
∫u'/u dx = ln|u|
∫u'·u^n dx = u^(n+1)/(n+1)
∫u'/sqrt(u) dx = 2sqrt(u)
Proprietes
∫[a,b] f = -∫[b,a] f
∫[a,a] f = 0
∫[a,c] f = ∫[a,b]+∫[b,c]
Aire = |∫[a,b] f(x)dx|
Val. moy. = (1/(b-a))∫[a,b]f
Aire entre 2 courbes
Si f(x) ≥ g(x) sur [a,b] : Aire = ∫[a,b] [f(x)-g(x)] dx. Si signe variable : decouper aux points d'intersection et sommer les valeurs absolues.
• Aire toujours positive → valeur absolue ou decomposition
• Bien reperer quelle courbe est au-dessus de l'autre
lim
Limites
Croissances comparees, formes indeterminees
▼
e^x domine les polynomes
lim(x→+∞) e^x/x^n = +∞
lim(x→+∞) x^n/e^x = 0
lim(x→-∞) x^n·e^x = 0
ln domine par x^n
lim(x→+∞) ln(x)/x^n = 0
lim(x→0+) x·ln(x) = 0
lim(x→0+) x^n·ln(x) = 0
Limites remarquables
lim(x→0) sin(x)/x = 1
lim(x→0) (e^x-1)/x = 1
lim(x→0) ln(1+x)/x = 1
💡 Formes indeterminees : ∞/∞ → factoriser par terme dominant · 0×∞ → transformer · ∞-∞ → factoriser ou conjugue
ln
Fonction ln
Proprietes, derivee, etude
▼
Proprietes algebriques
ln(ab) = ln a + ln b
ln(a/b) = ln a - ln b
ln(a^n) = n·ln a
ln(1) = 0 · ln(e) = 1
ln(e^x) = x · e^(ln x) = x
Variation et limites
Domaine : ]0 ; +∞[
Croissante sur ]0;+∞[
lim(x→0+) ln x = -∞
lim(x→+∞) ln x = +∞
(ln x)' = 1/x
(ln u)' = u'/u
• ln non defini pour x ≤ 0 → toujours preciser le domaine
• ln(a+b) ≠ ln a + ln b (erreur tres frequente !)
• ln(x²) = 2ln|x| et non 2ln(x)
e^x
Fonction Exponentielle
Proprietes, derivee, equations
▼
Proprietes
e^(a+b) = e^a × e^b
e^(a-b) = e^a / e^b
(e^a)^n = e^(na)
1/e^x = e^(-x)
e^x > 0 pour tout x ∈ R
Derivee et variation
(e^x)' = e^x
(e^(ax))' = a·e^(ax)
(e^u)' = u'·e^u
Domaine : R · Croissante
lim(x→-∞) e^x = 0
• e^x > 0 toujours → utile pour tableaux de signe
• e^x = k (k>0) → x = ln(k)
• e^(x+2) = e²×e^x (factorisable)
y'
Equations Differentielles
y'=ay et y'=ay+b
▼
Equation y' = ay
Solutions : y = C·e^(ax) (C∈R)
Avec y(0)=y₀ :
→ y = y₀·e^(ax)
a>0 : croissante
a<0 : decroissante → 0
Equation y' = ay + b
Sol. part. : y* = -b/a
Sol. generale :
y = C·e^(ax) - b/a
C = y(0) + b/a
Methode
1. Trouver la solution generale avec C · 2. Condition initiale → trouver C · 3. Ecrire la solution particuliere · 4. Verifier en derivant
💡 Applications : croissance radioactive, refroidissement (Newton), interets composes continus.

🔢 Suites Numeriques

Arithmetiques, geometriques, recurrence, convergence

+d
Suite Arithmetique
u_(n+1) = u_n + r
▼
Terme general
u_n = u_0 + n·r
u_n = u_1 + (n-1)·r
u_n = u_p + (n-p)·r
Somme des termes
S = u_0+u_1+...+u_n
S = (n+1)×(u_0+u_n)/2
= nb_termes × (1er+der)/2

1+2+...+n = n(n+1)/2
Proprietes
r = u_(n+1) - u_n = cst
r > 0 → croissante
r < 0 → decroissante
r = 0 → constante
• De u_0 a u_n → n+1 termes · De u_1 a u_n → n termes (piege classique !)
×q
Suite Geometrique
u_(n+1) = q·u_n
▼
Terme general
u_n = u_0 × q^n
u_n = u_1 × q^(n-1)
u_n = u_p × q^(n-p)
Somme (q≠1)
S = u_0+...+u_n
S = u_0×(1-q^(n+1))/(1-q)

1+q+...+q^n =
(1-q^(n+1))/(1-q)
Convergence
|q| < 1 → u_n → 0
q = 1 → u_n = u_0 (cst)
|q| > 1 → u_n → ±∞
q = -1 → diverge
💡 Interets composes : C_n = C_0 × (1+t)^n avec t le taux annuel.
→L
Convergence & Recurrence
Limites, encadrement, demonstration
▼
Suites monotones bornees
Toute suite monotone et bornee est convergente.
Croissante et majoree → converge. Decroissante et minoree → converge.
Theoreme des gendarmes
Si u_n ≤ v_n ≤ w_n et lim u_n = lim w_n = L, alors lim v_n = L.
Raisonnement par recurrence
1. Initialisation : verifier P(0) ou P(1)
2. Heredite : supposer P(n) vraie (H.R.) et montrer P(n+1)
3. Conclusion : P(n) vraie pour tout n par le principe de recurrence
• Pour la limite d'une suite recurrente u_(n+1)=f(u_n) : si elle converge vers L, alors L=f(L). Resoudre l'equation !

🌀 Nombres Complexes

Formes algebrique, trigonometrique et exponentielle, geometrie

a+ib
Formes des Complexes
Algebrique, trigo, exponentielle
▼
Forme algebrique
z = a + ib
i² = -1
Re(z) = a · Im(z) = b
Conjugue : z̄ = a - ib
z·z̄ = a²+b² = |z|²
Module et argument
|z| = sqrt(a²+b²)
arg(z) = θ (mod 2π)
|z₁z₂| = |z₁|·|z₂|
arg(z₁z₂) = arg z₁+arg z₂
|z₁/z₂| = |z₁|/|z₂|
Forme exponentielle (Euler)
z = r·e^(iθ)
= r(cos θ + i sin θ)

Formule d'Euler :
e^(iθ) = cos θ + i sin θ
e^(iπ) + 1 = 0
z^n
Formules et Geometrie
Moivre, Euler, plan complexe
▼
Formule de Moivre
(cos θ+i sin θ)^n =
cos(nθ)+i sin(nθ)

(r·e^(iθ))^n = r^n·e^(inθ)
Formules d'Euler
cos θ = (e^(iθ)+e^(-iθ))/2
sin θ = (e^(iθ)-e^(-iθ))/(2i)
Geometrie dans le plan
|z_B - z_A| = AB
arg(z_B-z_A) = angle(AB)
Milieu : (z_A+z_B)/2
Delta<0 → z = (-b±i√|Δ|)/(2a)
• arg(z) : trouver θ avec cos θ=a/r et sin θ=b/r → choisir θ dans ]-π;π]
• z/z̄ = e^(2iθ) et |z|² = z·z̄

🎲 Probabilites et Statistiques

Variables aleatoires, loi normale, intervalles de confiance, tests d'hypotheses

E(X)
Variables Aleatoires
Esperance, variance, loi binomiale
▼
Esperance
E(X) = Σ xᵢ·P(X=xᵢ)
E(aX+b) = aE(X)+b
E(X+Y) = E(X)+E(Y)
Variance et ecart-type
V(X) = E(X²)-[E(X)]²
V(aX+b) = a²V(X)
σ(X) = sqrt(V(X))
Loi binomiale B(n,p)
P(X=k) = C(n,k)p^k(1-p)^(n-k)
E(X) = np
V(X) = np(1-p)
σ = sqrt(np(1-p))
N(μ,σ)
Loi Normale
Loi de Gauss, standardisation, approximation
▼
N(0,1) — Valeurs a connaitre
P(-1,96 ≤ Z ≤ 1,96) ≈ 0,95
P(-2,58 ≤ Z ≤ 2,58) ≈ 0,99
P(-1 ≤ Z ≤ 1) ≈ 0,68
P(-1,645 ≤ Z ≤ 1,645) ≈ 0,90
Standardisation
Si X ~ N(μ,σ²) :
Z = (X-μ)/σ ~ N(0,1)

Symetrie :
P(Z ≤ -a) = 1-P(Z ≤ a)
Approximation binomiale
Si np ≥ 5 et n(1-p) ≥ 5 :
B(n,p) ≈ N(np, np(1-p))
IC
Intervalles de Confiance et Tests
IC 95%, intervalle de fluctuation, test d'hypothese
▼
Intervalle de confiance (95%)
Frequence f, taille n :
IC = [f-1/sqrt(n) ; f+1/sqrt(n)]

Formule exacte :
[f-1,96·sqrt(f(1-f)/n) ;
f+1,96·sqrt(f(1-f)/n)]
Intervalle de fluctuation (95%)
p connu, taille n :
IF = [p-1/sqrt(n) ; p+1/sqrt(n)]

f ∈ IF → ne pas rejeter H₀
f ∉ IF → rejeter H₀
Demarche du test d'hypothese
1. Poser H₀ (ex: p=0,5) et H₁ (ex: p≠0,5) · 2. Fixer le seuil α (souvent 5%) · 3. Calculer l'intervalle de fluctuation · 4. Observer la frequence f · 5. Conclure : f ∉ IF → rejeter H₀ au seuil α
• "Ne pas rejeter H₀" ≠ "H₀ est vraie" — nuance obligatoire dans la redaction !
• La formule 1/sqrt(n) est une approximation valable pour n ≥ 30

Vecteurs dans l'espace
Coordonnees, norme, produit scalaire
▼
Coordonnees et norme
AB = B-A = (xB-xA, yB-yA, zB-zA)
|AB| = sqrt((xB-xA)²+(yB-yA)²+(zB-zA)²)
Milieu M = ((xA+xB)/2,...)
Produit scalaire
u·v = xx'+yy'+zz'
u·v = |u||v|cos θ
u⊥v ⟺ u·v = 0
|u|² = x²+y²+z²
Colinearite
u et v colineaires ⟺
∃k : u = k·v
⟺ coordonnees proportionnelles
plan
Droites et Plans
Equations, positions relatives, distances
▼
Rep. parametrique d'une droite
Par A(a,b,c), dir. u(l,m,n) :
x = a+tl
y = b+tm (t∈R)
z = c+tn
Equation d'un plan
ax+by+cz+d = 0
Vecteur normal : n=(a,b,c)
Par A(x₀,y₀,z₀) :
a(x-x₀)+b(y-y₀)+c(z-z₀)=0
Distance point-plan
d(M, ax+by+cz+d=0) =
|ax₀+by₀+cz₀+d|/sqrt(a²+b²+c²)
